# アバターの画像を置く場所

ここに画像を置いて、`src/data/avatarAssets.ts` の `enabled` を `true` にすると、
組み込みの絵のかわりにその画像が使われます。

## 用意するファイル

| ファイル名 | 使われる場面 | 必須 |
| --- | --- | --- |
| `idle.png` | 待機中。ほかの絵がないときの代用にもなる | ◎ |
| `speaking-1.png` `speaking-2.png` | 話しているあいだ交互に出す（口パク） | ○ |
| `listening.png` | 生徒の声を聞いているあいだ | ○ |
| `thinking.png` | 答えを確認しているあいだ | △ |
| `happy.png` | 開始画面と、聞き取りが終わったとき | △ |
| `confused.png` | うまく聞き取れなかったとき | △ |
| `blink.png` | まばたき用（目を閉じた絵） | △ |

`idle.png` の 1 枚だけでも動きます。足りない表情は `idle.png` で代用されます。

## 画像の条件

- **サイズ: 1024 × 1024 px（正方形）** を推奨。画面上は最大 340px 程度で表示するため、
  画面密度 3 倍の端末でも足ります
- **形式: PNG（背景透過）**。ベクターの素材なら `.svg` でもそのまま使えます
- **1 枚 300KB 以下・合計 2MB 以下** が目安。`.webp` にすると 1/3 ほどになります
- **すべての絵でキャンバスの大きさと、キャラクターの位置・大きさをそろえてください。**
  ここがずれると、表情が変わるたびに絵が跳ねて見えます

## 動く素材を使いたいとき

アニメーション GIF / APNG / アニメーション WebP もそのまま指定できます。
その表情のあいだだけ再生されるので、`speaking` に口パクの動画を割り当てる使い方ができます。

```ts
speaking: 'avatar/speaking.webp',
```
