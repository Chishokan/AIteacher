# AItecher｜成績ヒアリング

タブレット上のアバターが生徒に音声で問いかけ、生徒が音声で答える聞き取りアプリです。
定期テストの得点や通知表の評定など、**あらかじめ決めた内容**を順番に読み上げ、
返ってきた声を数値・選択肢・文章として記録します。

- 女性型アンドロイドのアバターが、口パク・まばたき・うなずき・ランプの明滅で、
  いま話しているのか聞いているのかを伝えます
- 答えは復唱して「あっていますか」と確認してから確定します
- 「わからない」でスキップ、「もう一度言って」で読み上げのやり直し
- 音声が使えないときは、画面のテンキー・ボタンからそのまま入力できます
- 結果は一覧表示・CSV / JSON 書き出し・印刷ができます

## 動作環境

| 必要なもの | 備考 |
| --- | --- |
| ブラウザ | Chrome / Edge / Safari（iPadOS 14.5 以降）。Web Speech API を使います |
| 接続 | マイクを使うため **https または localhost** で開く必要があります |
| 音声 | 端末に日本語の音声（読み上げ）が入っていること |

Firefox は音声認識に対応していないため、画面入力のみで動作します。

## 使い方

```bash
npm install
npm run dev      # http://localhost:5173
```

同じネットワークのタブレットから試す場合は、`npm run dev` が表示する
`Network:` の URL を開いてください。マイクの許可を求められたら「許可」を選びます。

> `http://` の LAN アドレスではマイクがブロックされます。実機で音声を使うときは、
> https で配信するか、`npm run build` した `dist/` を https のサーバーに置いてください。

本番用のビルドと確認：

```bash
npm run build
npm run preview
```

### 面談の流れ

1. 生徒の名前を入れて「はじめる」
2. アバターが質問を読み上げ、マイクのマークが光ったら生徒が声で答える
3. 得点・評定は復唱して確認（「はい」で確定、「いいえ」で言い直し）
4. 全部答え終わると結果画面。CSV / JSON で書き出せます

### 生徒が使える言い方

| 言い方 | 動き |
| --- | --- |
| 「78点」「ななじゅうはちてん」「七十八点」 | 得点として記録 |
| 「4」「よん」「四です」 | 評定として記録（1〜5） |
| 「はい」「うん」「あってます」 | 確認に対する肯定 |
| 「いいえ」「ちがいます」 | 確認に対する否定（言い直しへ） |
| 「わからない」「覚えてない」 | その質問をとばす |
| 「もう一度言って」 | 質問を読み直す |

聞き取れない状態が 3 回続くと、質問文といっしょに「画面のボタンからも入力できます」と案内します。

## 質問内容を変える

「設定」画面から、この端末の中だけで変更できます。

- 面談の名前
- 定期テストで点数を聞く教科（追加・削除）
- 通知表で評定を聞く教科（追加・削除）
- 定期テストの満点
- 声・話す速さ・高さ、話し始めるまでの待ち時間
- 答えを復唱して確認するかどうか

シナリオそのものを組み替えたい場合は `src/data/scenario.ts` の `buildScenario()` を編集してください。
質問は `Question` 型（`score` / `grade` / `choice` / `yesno` / `free`）の配列です。

## データの扱い

- 回答はブラウザの `localStorage` にのみ保存され、外部には送信されません
- 端末を共有する場合は、「これまでの記録」から不要な記録を削除してください
- 音声認識そのものは、ブラウザによってはベンダーのサーバーで処理されます（Chrome など）

## 構成

```
src/
├── data/scenario.ts        あらかじめ決めた質問（定期テスト・通知表・ふりかえり）
├── speech/tts.ts           読み上げ（SpeechSynthesis）
├── speech/stt.ts           聞き取り（SpeechRecognition）
├── logic/japaneseNumber.ts 「ななじゅうはち」「七十八」→ 78 の変換
├── logic/parseAnswer.ts    聞き取った文を質問の形式に合わせて解釈
├── logic/interview.ts      復唱文・集計・CSV 出力
├── hooks/useInterview.ts   面談の進行（読み上げ → 聞き取り → 確認 → 次へ）
└── components/             アバター・面談画面・結果・設定・履歴
```
