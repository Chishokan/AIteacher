# 音声ファイルを置く場所

読み上げ（ブラウザの音声合成）のかわりに、あらかじめ用意した音声を鳴らすための素材です。

- `manifest.csv` … 収録が必要なメッセージの一覧（Excel で開けます）
- `manifest.json` … 同じ内容を、アプリから読める形にしたもの
- 音声ファイルは、このフォルダに **ID と同じ名前** で置いてください（例 `greeting.mp3`）

一覧は `src/data/scenario.ts` から作っています。教科を増やしたり質問を変えたら、
作り直すと一覧も追従します。

```bash
node --experimental-strip-types scripts/gen-audio-manifest.mjs
```

## ファイルの条件

| 項目 | 推奨 |
| --- | --- |
| 形式 | **MP3**（iPad / Android / PC すべてで鳴ります） |
| チャンネル | モノラル |
| サンプリング | 44.1 kHz |
| ビットレート | 96〜128 kbps |
| 音量 | 全ファイルでそろえる（-16 LUFS 目安） |
| 前後の無音 | **50 ミリ秒以下に切りつめる** |

前後の無音と音量は、つなげて鳴らすファイルがあるため特に大事です。
ファイルごとに無音の長さや音量が違うと、つなぎ目で不自然に途切れて聞こえます。

## ふだんの運用と、追加設定

アプリは既定では**定期テストの得点だけ**を聞きます。通知表の評定・ふりかえり・次の目標は、
設定画面の「追加で聞く内容」でオンにしたときだけ質問に入ります。

`manifest.csv` の「テスト運用」列を見てください。

| 列の値 | 意味 |
| --- | --- |
| 必要 | 既定の運用（定期テストのみ）で使うもの。**19 本** |
| 追加設定のとき | 通知表・ふりかえり・次の目標をオンにしたときだけ使うもの |

## 同じ文章のものは 1 本にまとめています

「同じ音声を使う場面」列に、その音声がどこで使われるかが並びます。

| ファイル | 使われる場面 |
| --- | --- |
| `again.mp3`「ごめんなさい。もう一度お願いします。」 | 得点・評定が聞き取れなかったとき（教科を問わず共通） |
| `err-choice.mp3`「選択肢の中から、いちばん近いものを選んで言ってください。」 | 「今回の手ごたえ」の言い直しと、選択肢が聞き取れなかったとき |

教科名を読み上げる言い直し（「もう一度お願いします。国語の点数を…」）はやめました。
教科を増やしても、増えるのは質問 1 本だけです。

## つなげて鳴らすファイルはありません

すべて 1 ファイルで完結します。

答えを確認するときも、**聞き取った値は音声で読み上げません。**
画面に大きく出して、アバターは「こちらの点数であっていますか。」とだけ言います。

```
画面：  国語の得点
        ┌──────────────┐
        │    78点      │   ← 大きく表示
        └──────────────┘
        [ はい、あっています ]  [ いいえ、ちがいます ]

音声：  confirm-score.mp3 「こちらの点数であっていますか。」
```

生徒は声で「はい」「いいえ」と答えても、画面のボタンを押しても進めます。

## 確認するのは得点と評定だけです

聞き間違いが記録に残ると困るのは数値だけなので、確認はそこに絞っています。
選択肢と自由記述は確認しません。

## 文言について

生徒が何を言うか決まらない部分は、そのままでは音声にできないため、値を読み上げない言い方にしてあります。

| もとの言い方 | いまの言い方 |
| --- | --- |
| 「国語の得点は、78点ですね。あっていますか。」 | 「こちらの点数であっていますか。」（値は画面） |
| 「もう一度お願いします。国語の点数を、数字で言ってください。」 | 「ごめんなさい。もう一度お願いします。」 |
| 「150点は満点をこえています。0から100までで言ってください。」 | 「満点をこえています。0から100までの数字で言ってください。」 |
| 「78点 ですね。ありがとう。」（画面入力を受けたとき） | 「ありがとう。」 |

## 設定を変えると必要なファイルが変わります

- **教科を足す / 減らす** … 質問が 1 本増減します（言い直しは `again.mp3` を使いまわします）
- **満点を 100 点から変える** … `err-score-format` と `err-score-over` を録り直します
- **通知表・ふりかえり・次の目標をオンにする** … 「テスト運用」列が「追加設定のとき」の音声が要ります
- **「答えを確認する」を切る** … `confirm-score` `confirm-grade` `confirm-retry` が不要になります

いずれの場合も、`manifest.csv` を作り直せば必要な一覧が出ます。
