# アバターの画像を置く場所

アバターは「プリセット」として `src/data/avatarPresets.ts` に登録し、
設定画面の「アバター」から選びます。画像はプリセットごとにフォルダを分けて置いてください。

```
public/avatar/
├── male/         ← ティーチャー（男性）
│   ├── idle.webp
│   ├── speaking-1.webp
│   └── ...
└── <好きな名前>/  ← 追加するアバター
    └── idle.webp
```

**画像はキャラクターごとにフォルダを分けて置いてください。**
`public/avatar/` の直下に置くと、別のキャラクターを足したときに名前がぶつかります。

## プリセットを追加する

1. `public/avatar/<フォルダ名>/` に画像を置く
2. `src/data/avatarPresets.ts` の `AVATAR_PRESETS` に 1 つ足す

```ts
{
  id: 'female-teacher',
  name: 'ティーチャー（女性）',
  description: '画像素材（public/avatar/female/）',
  kind: 'images',
  images: {
    idle: 'avatar/female/idle.png',
    speaking: ['avatar/female/speaking-1.png', 'avatar/female/speaking-2.png'],
  },
  framed: true,   // 背景が透過していない素材のとき
},
```

**`images` には、実際に置いた絵だけを書いてください。** 書いたのにファイルが無いと
読み込みに失敗します（そのときは組み込みの絵に自動で戻ります）。

## 表情ごとの画像

| キー | 使われる場面 | 必須 |
| --- | --- | --- |
| `idle` | 待機中。ほかの絵がないときの代用にもなる | ◎ |
| `speaking` | 話しているあいだ。配列で複数枚わたすと交互に出て口パクになる | ○ |
| `listening` | 生徒の声を聞いているあいだ | ○ |
| `thinking` | 答えを確認しているあいだ | △ |
| `happy` | 開始画面と、聞き取りが終わったとき | △ |
| `confused` | うまく聞き取れなかったとき | △ |
| `blink` | まばたき用（目を閉じた絵） | △ |

`idle` の 1 枚だけでも動きます。足りない表情は `idle` で代用されます。

## 画像の条件

- **サイズ: 1024 × 1024 px（正方形）** を推奨。画面上は最大 340px 程度で表示するため、
  画面密度 3 倍の端末でも足ります
- **形式: 透過 WebP を推奨**（PNG でも動きます）。背景が透過していれば、そのまま画面になじみます。
  白背景などの素材は、プリセットに `framed: true` を付けると角の丸い枠に収めて表示します
- **1 枚 300KB 以下・合計 2MB 以下** が目安。
  アプリは表情の絵をまとめて先読みするため、PNG のままだと初回の読み込みが重くなります。
  1024px・品質 85% 程度の WebP に変換すると、見た目を保ったまま 1/10 ほどになります
- **すべての絵でキャンバスの大きさと、キャラクターの位置・大きさをそろえてください。**
  ここがずれると、表情が変わるたびに絵が跳ねて見えます

アニメーション GIF / APNG / アニメーション WebP もそのまま指定できます。
その表情のあいだだけ再生されるので、`speaking` に口パクの動画を割り当てる使い方ができます。
