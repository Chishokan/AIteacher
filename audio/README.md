# 音声ファイルを置く場所

読み上げ（ブラウザの音声合成）のかわりに、あらかじめ用意した音声を鳴らすための素材です。

- `manifest.csv` … 収録が必要なメッセージの一覧（Excel で開けます）
- `manifest.json` … 同じ内容を、アプリから読める形にしたもの
- 音声ファイルは、このフォルダに **ID と同じ名前** で置いてください（例 `greeting.mp3`）

一覧は `src/data/scenario.ts` から作っています。教科を増やしたり質問を変えたら、
作り直すと一覧も追従します。

```bash
node --experimental-strip-types scripts/gen-audio-manifest.mjs
```

## ファイルの条件

| 項目 | 推奨 |
| --- | --- |
| 形式 | **MP3**（iPad / Android / PC すべてで鳴ります） |
| チャンネル | モノラル |
| サンプリング | 44.1 kHz |
| ビットレート | 96〜128 kbps |
| 音量 | 全ファイルでそろえる（-16 LUFS 目安） |
| 前後の無音 | **50 ミリ秒以下に切りつめる** |

前後の無音と音量は、つなげて鳴らすファイルがあるため特に大事です。
ファイルごとに無音の長さや音量が違うと、つなぎ目で不自然に途切れて聞こえます。

## つなげて鳴らすもの

答えを復唱して確認するときだけ、2 つのファイルを続けて鳴らします。

| 場面 | 鳴らす順 | 例 |
| --- | --- | --- |
| 得点の確認 | `confirm-lead-test-01` → `confirm-score-78` | 「国語の得点は、」「78点ですね。あっていますか。」 |
| 評定の確認 | `confirm-lead-report-03` → `confirm-grade-4` | 「数学の評定は、」「4ですね。あっていますか。」 |

前半（`confirm-lead-*`）は**言い切らず、次に続く調子**で。
後半（`confirm-score-*` / `confirm-grade-*`）は**文の途中から始まる調子**で収録してください。

これ以外はすべて 1 ファイルで完結します。

## 文言を変えてある箇所

生徒が何を言うか決まらない部分は、そのままでは音声にできないため、言い方を変えています。
音声を組み込むときに、アプリ側も合わせて直します。

| 変える前（読み上げ） | 変えたあと（音声） | 理由 |
| --- | --- | --- |
| 「（生徒の言葉）ですね。あっていますか。」 | 「画面に出ている内容で、あっていますか。」 | 自由記述は事前に録れない。画面に文字が出ているので、そこを見てもらう |
| 「150点は満点をこえています。0から100までで言ってください。」 | 「満点をこえています。0から100までの数字で言ってください。」 | 数字を読み上げると、点数ぶんのファイルが必要になる |
| 「78点 ですね。ありがとう。」（画面入力を受けたとき） | 「ありがとう。」 | 同上 |

## 設定を変えると必要なファイルが変わります

- **教科を足す / 減らす** … その教科の質問・聞き直し・確認の前半が増減します（1 教科につき 3 本）
- **満点を 100 点から変える** … `confirm-score-*`、`err-score-format`、`err-score-over` を録り直します
- **「答えを復唱して確認する」を切る** … `confirm-*` の 112 本が不要になります

いずれの場合も、`manifest.csv` を作り直せば必要な一覧が出ます。
