# AItecher｜成績ヒアリング

タブレット上のアバターが生徒に音声で問いかけ、生徒が音声で答える聞き取りアプリです。
定期テストの得点など、**あらかじめ決めた内容**を順番に読み上げ、
返ってきた声を数値・選択肢・文章として記録します。

- 女性型アンドロイドのアバターが、口パク・まばたき・うなずき・ランプの明滅で、
  いま話しているのか聞いているのかを伝えます
- 答えは復唱して「あっていますか」と確認してから確定します
- 「わからない」でスキップ、「もう一度言って」で読み上げのやり直し
- 音声が使えないときは、画面のテンキー・ボタンからそのまま入力できます
- 結果は一覧表示・CSV / JSON 書き出し・印刷ができます

## 動作環境

| 必要なもの | 備考 |
| --- | --- |
| ブラウザ | Chrome / Edge / Safari（iPadOS 14.5 以降）。Web Speech API を使います |
| 接続 | マイクを使うため **https または localhost** で開く必要があります |
| 音声 | 端末に日本語の音声（読み上げ）が入っていること |

Firefox は音声認識に対応していないため、画面入力のみで動作します。

## 使い方

```bash
npm install
npm run dev      # http://localhost:5173
```

同じネットワークのタブレットから試す場合は、`npm run dev` が表示する
`Network:` の URL を開いてください。マイクの許可を求められたら「許可」を選びます。

> `http://` の LAN アドレスではマイクがブロックされます。実機で音声を使うときは、
> https で配信するか、`npm run build` した `dist/` を https のサーバーに置いてください。

本番用のビルドと確認：

```bash
npm run build
npm run preview
```

### 面談の流れ

1. 生徒の名前を入れて「はじめる」
2. アバターが質問を読み上げ、マイクのマークが光ったら生徒が声で答える
3. 得点・評定は復唱して確認（「はい」で確定、「いいえ」で言い直し）
4. 全部答え終わると結果画面。CSV / JSON で書き出せます

### 生徒が使える言い方

| 言い方 | 動き |
| --- | --- |
| 「78点」「ななじゅうはちてん」「七十八点」 | 得点として記録 |
| 「4」「よん」「四です」 | 評定として記録（1〜5） |
| 「はい」「うん」「あってます」 | 確認に対する肯定 |
| 「いいえ」「ちがいます」 | 確認に対する否定（言い直しへ） |
| 「わからない」「覚えてない」 | その質問をとばす |
| 「もう一度言って」 | 質問を読み直す |

聞き取れない状態が 3 回続くと、質問文といっしょに「画面のボタンからも入力できます」と案内します。

### マイクの許可について

読み上げが終わってから音声認識が始まるため、画面をタップしてから 20 秒ほど経ちます。
ブラウザが「ユーザー操作の直後」とみなす時間（Chrome では 5 秒）を過ぎていると、
許可を聞くダイアログが出ないまま不許可で進んでしまいます。

そこで、**「はじめる」を押したその場で `getUserMedia` を呼んで許可を取ります**。
一度許可すればサイトごとに覚えられるので、あとから始まる音声認識も動きます。

それでも音声認識を始められない端末（タップの直後でないと始められないもの）では、
**「タップして話す」ボタン**を画面に大きく出します。押した直後にマイクが開きます。

## 何を聞くか

既定では**定期テストの得点だけ**を聞きます（準備確認 1 問＋教科ぶん）。
通知表の評定・ふりかえり・次の目標は、「設定」画面の**「追加で聞く内容」**でオンにしたときだけ質問に入ります。

| 章 | 既定 | 中身 |
| --- | --- | --- |
| はじめに | 入る | 準備はいいですか（1 問） |
| 定期テストの得点 | 入る | 教科ぶん（既定 5 教科） |
| 通知表の評定 | 追加設定 | 教科ぶん（既定 9 教科） |
| ふりかえり | 追加設定 | 今回の手ごたえ、そう感じた理由（2 問） |
| 次の目標 | 追加設定 | 伸ばしたい教科、目標点、今日から始めること（3 問） |

## 設定を変える

「設定」画面から、この端末の中だけで変更できます。

- 面談の名前
- アバターの見た目
- 追加で聞く内容（通知表・ふりかえり・次の目標）
- 定期テストで点数を聞く教科（追加・削除）
- 定期テストの満点
- 声・話す速さ・高さ、話し始めるまでの待ち時間
- 答えを確認するかどうか（聞き取った得点・評定を画面に出して確かめてもらう）

シナリオそのものを組み替えたい場合は `src/data/scenario.ts` の `buildScenario()` を編集してください。
質問は `Question` 型（`score` / `grade` / `choice` / `yesno` / `free`）の配列です。

## アバターを切り替える／差し替える

アバターは「プリセット」として登録し、**設定画面の「アバター」から選べます**。
選んだ内容はこの端末に保存されます。

最初から入っているプリセット：

| プリセット | 中身 |
| --- | --- |
| アンドロイド（女性） | 組み込みの絵。コードで描いているので素材がなくても動きます |
| ティーチャー（男性） | 画像素材。8 つの表情（口パク・まばたき込み）を `public/avatar/male/` に置いています |

### 画像素材を追加する

1. 画像を `public/avatar/<フォルダ名>/` に置く
2. `src/data/avatarPresets.ts` の `AVATAR_PRESETS` に 1 つ足す

```ts
{
  id: 'female-teacher',
  name: 'ティーチャー（女性）',
  description: '画像素材（public/avatar/female/）',
  kind: 'images',
  images: {
    idle: 'avatar/female/idle.png',
    speaking: ['avatar/female/speaking-1.png', 'avatar/female/speaking-2.png'],
  },
  framed: true,   // 背景が透過していない素材のとき
},
```

`images` には**実際に置いた絵だけ**を書いてください。書いたのにファイルが無い場合は、
面談が止まらないよう組み込みの絵に自動で戻り、設定画面に「画像が見つかりません」と出ます。

### 表情ごとの画像

| キー | 使われる場面 | 必須 |
| --- | --- | --- |
| `idle` | 待機中。ほかの絵がないときの代用にもなる | ◎ |
| `speaking` | 話しているあいだ。配列にすると交互に出て口パクになる | ○ |
| `listening` | 生徒の声を聞いているあいだ | ○ |
| `thinking` | 答えを確認しているあいだ | △ |
| `happy` | 開始画面と、聞き取りが終わったとき | △ |
| `confused` | うまく聞き取れなかったとき | △ |
| `blink` | まばたき用（目を閉じた絵） | △ |

`idle` の 1 枚だけでも動きます。

### 画像の条件

| 項目 | 推奨 |
| --- | --- |
| サイズ | **1024 × 1024 px（正方形）**。画面上は最大 340px 程度なので、画面密度 3 倍の端末でも足ります |
| 形式 | **透過 WebP を推奨**（PNG でも動きます）。白背景の素材は `framed: true` で角の丸い枠に収まります |
| 容量 | 1 枚 300KB 以下・合計 2MB 以下が目安。表情の絵はまとめて先読みするため、PNG のままだと初回が重くなります |
| そろえること | **すべての絵で、キャンバスの大きさとキャラクターの位置・大きさを同じにする** |

最後の項目がいちばん大事です。絵ごとに顔の位置がずれていると、表情が変わるたびに跳ねて見えます。

アニメーション GIF / APNG / アニメーション WebP も指定できます。その表情のあいだだけ再生されるので、
`speaking` に口パクの動画を割り当てる使い方もできます。

口パクの速さやまばたきの間隔は、プリセットの
`mouthFrameMs` / `blinkIntervalMs` で調整できます。

## 読み上げを、用意した音声に置き換える

`public/audio/` に音声ファイルを置くと、その文章は読み上げではなく音声で鳴ります。
**置かれていないものは読み上げにまわる**ので、全部そろっていなくても動きます。

```bash
# 収録が必要なメッセージの一覧を作る（public/audio/manifest.csv）
node --experimental-strip-types scripts/gen-audio-manifest.mjs

# いま何本そろっていて、何が足りないかを見る
node scripts/check-audio.mjs
```

同じ文章になるものは 1 本にまとめてあります（教科ごとの言い直しは
`again.mp3`「ごめんなさい。もう一度お願いします。」で共通）。
既定の運用に必要なのは 19 本、追加設定ぶんを入れても 41 本です。
収録の条件は `public/audio/README.md` を見てください。

## データの扱い

- 回答はブラウザの `localStorage` にのみ保存され、外部には送信されません
- 端末を共有する場合は、「これまでの記録」から不要な記録を削除してください
- 音声認識そのものは、ブラウザによってはベンダーのサーバーで処理されます（Chrome など）

## 構成

```
src/
├── data/scenario.ts        あらかじめ決めた質問（定期テスト、および追加設定ぶん）
├── speech/tts.ts           読み上げ（SpeechSynthesis）
├── speech/clips.ts         用意した音声の再生と、無いときの読み上げへの切り替え
├── speech/stt.ts           聞き取り（SpeechRecognition）
├── logic/japaneseNumber.ts 「ななじゅうはち」「七十八」→ 78 の変換
├── logic/parseAnswer.ts    聞き取った文を質問の形式に合わせて解釈
├── logic/interview.ts      復唱文・集計・CSV 出力
├── hooks/useInterview.ts   面談の進行（読み上げ → 聞き取り → 確認 → 次へ）
├── data/avatarPresets.ts   アバターの候補（組み込みの絵・画像素材）
└── components/             アバター・面談画面・結果・設定・履歴
    ├── Avatar.tsx          選ばれた見た目を描く窓口
    ├── DrawnAvatar.tsx     組み込みの絵（コードで描いている）
    ├── ImageAvatar.tsx     画像素材の表示と口パク・まばたき
    └── AvatarPicker.tsx    設定画面のアバター選択
```
